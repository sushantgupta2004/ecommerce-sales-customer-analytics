# 📊 E-Commerce Sales & Customer Analytics

An end-to-end portfolio project analyzing e-commerce sales, profitability, product performance, regional trends and customer behavior.

> **Note:** The included dataset is a realistic synthetic dataset created for portfolio/learning purposes. It is not a real company's customer data.

## 🎯 Objectives
- Analyze sales and profit trends
- Identify top-performing products and categories
- Compare regional performance
- Calculate core business KPIs
- Perform RFM customer segmentation
- Provide an interactive Streamlit dashboard
- Demonstrate SQL analysis skills

## 🛠️ Tech Stack
Python • Pandas • NumPy • Matplotlib • SQL • Streamlit • Jupyter Notebook • GitHub

## 📌 Key KPIs
- Total Sales: ₹65,731,839
- Total Profit: ₹15,391,829
- Orders: 3,500
- Customers: 597
- Average Order Value: ₹18,781
- Profit Margin: 23.42%

## 📂 Project Structure
```text
data/       → datasets and RFM segments
figures/    → analysis charts
notebooks/  → Jupyter analysis
sql/        → SQL queries
src/        → Python analysis script
app.py      → Streamlit dashboard
```

## ▶️ Run Locally
```bash
pip install -r requirements.txt
streamlit run app.py
```

## 📈 Analysis Areas
1. Data quality and preprocessing
2. Sales and profit KPIs
3. Monthly sales trends
4. Category and product performance
5. Regional performance
6. Payment and order-status analysis
7. RFM customer segmentation

## 💡 Business Insights
- Use monthly sales trends to plan inventory and marketing campaigns.
- Prioritize high-sales/high-profit products.
- Compare regional performance when allocating marketing budgets.
- Use RFM segments to target loyal and at-risk customers differently.
